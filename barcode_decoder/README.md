# Barcode Decoder

Legge i codici a barre di foto e PDF: immagine o PDF in ingresso, testo dei codici in uscita. Nessun dato salvato.

Reads the barcodes of photos, screenshots and PDFs (JPEG, PNG, WebP, HEIC, PDF) for Home Assistant integrations
and other local services: the file goes in, the texts of the barcodes come out. Stateless: no database, no users,
no tokens, no outbound connection, and no host port (it is reached on Home Assistant's internal network).

See the Documentation tab for the address to use and the API.
